# Tsunami Bay

80-yillar neon shahar uslubidagi 3D brauzer o'yini (three.js). Telefon va kompyuterda ishlaydi.

**O'ynash:** https://mrsilverstar1210-beep.github.io/tsunami-bay/

## Imkoniyatlar
- Ochiq shahar: plyaj, okean, palmalar, neon binolar, kun–tun almashinuvi
- Piyoda yurish, mashinaga minish/tushish, ko'chadagi mashinani tortib olish
- Musht, to'pponcha, Uzi, drobovik
- Politsiya va qidiruv yulduzlari (★1–6), "Qo'lga olindi" / "Halok bo'ldingiz"
- Pul, sog'liq, zirh va qurol topilmalari
- Missiyalar: Taksi, Yetkazib berish, Ko'cha bezorilari, Plyaj poygasi
- Mashina shikastlanishi va portlash
- Radio: Tsunami FM, Neon Xorazm
- Poyga rejimi va garaj (25 mashina, Tripo modellari)

## Boshqaruv (kompyuter)
W/A/S/D — yurish/haydash · Shift — yugurish/nitro · Space — sakrash/qo'l tormozi · E — minish/tushish ·
F / sichqoncha — hujum · Q — qurol (piyoda) / radio (mashinada) · C — kamera · R — tiklash · Esc — pauza
